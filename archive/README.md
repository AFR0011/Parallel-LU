project's authentic development history. It is not built, tested, or supported.

The file had drifted from `lu_driver.cpp`: despite the old README description,
it does not provide the serial fallback. The maintained coursework path is the
root-level `lu_driver.cpp` plus `lu_worker.cpp` pair.
